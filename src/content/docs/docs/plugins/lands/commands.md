# Lands コマンド一覧

Landsで使用できるコマンドを、目的別にまとめています。ほとんどの機能はゲーム内メニュー（`/lands menu`）からも操作できますが、コマンド操作に慣れている方向けに一覧を掲載します。

:::tip[edit land について]

多くのコマンドは、`/lands edit <土地名>` で選択した「編集対象の土地」に対して実行されます。自分が信頼されている土地が1つだけの場合は、自動的にその土地が対象になります。

:::

## 基本コマンド

| コマンド | 説明 |
| --- | --- |
| `/lands` または `/lands menu` | Landsのメインメニューを開きます。 |
| `/lands help [ページ]` | コマンドのヘルプを表示します。 |
| `/lands info [土地名]` | 土地の情報を表示します。 |
| `/lands info player <プレイヤー名>` | 指定したプレイヤーの情報を表示します。 |
| `/lands map` | 周辺の土地の地図を表示します。 |
| `/lands list` | サーバー内の土地の一覧を表示します。 |
| `/lands top` | 土地のランキング（上位10件など）を表示します。 |

## 土地の作成・削除

| コマンド | 説明 |
| --- | --- |
| `/lands create [名前]` | 新しい土地を作成します。 |
| `/lands createcamp` | 一定期間で自動的に削除される、一時的な土地（キャンプ）を作成します。 |
| `/lands delete` | 編集中の土地を削除します。 |
| `/lands rename <名前>` | 土地の名前を変更します。 |
| `/lands merge <土地名>` | 指定した土地を、編集中の土地に統合します。 |
| `/lands edit <土地名>` | 以降のコマンドの対象となる土地を選択します。 |

## 土地の保護（クレーム）

| コマンド | 説明 |
| --- | --- |
| `/lands claim` | 立っているチャンクを保護します。 |
| `/lands claim auto` | 歩きながら自動で保護します。 |
| `/lands claim radius <数値>` | 自分を中心とした範囲のチャンクをまとめて保護します。 |
| `/lands claim fill` | 保護済みの土地に囲まれた未保護のチャンクをまとめて保護します。 |
| `/lands claim list` | 編集中の土地が保護しているチャンクの一覧を表示します。 |
| `/lands unclaim` | 立っているチャンクの保護を解除します。 |
| `/lands unclaim auto` | 歩きながら自動で保護を解除します。 |
| `/lands unclaimall` | 編集中の土地が保護しているチャンクをすべて解除します。 |
| `/lands selection` | `claim` や `unclaim`、`trust` などをまとめて実行するための範囲選択を行います。 |
| `/lands assign <エリア名>` | 選択範囲を、既存のサブエリアのサイズ変更または新規作成に割り当てます。 |

## メンバー・信頼関係

| コマンド | 説明 |
| --- | --- |
| `/lands trust <プレイヤー名> [エリア]` | プレイヤーを信頼し、土地（またはエリア）へのアクセスを許可します。 |
| `/lands untrust <プレイヤー名> [エリア]` | 信頼を解除します。 |
| `/lands setrole <プレイヤー名> <ロール名> [エリア]` | プレイヤーのロール（役職）を設定します。 |
| `/lands setowner <プレイヤー名>` | 土地のオーナー権限を譲渡します。 |
| `/lands invites` | 受け取っている招待の一覧を表示します。 |
| `/lands accept <土地名>` | 招待を承諾します。 |
| `/lands deny <土地名>` | 招待を拒否します。 |
| `/lands leave [エリア]` | 土地（または特定のエリア）から脱退します。 |
| `/lands chat [土地名]` | 土地専用チャットの発言先を切り替えます。 |

## 経済・維持費

| コマンド | 説明 |
| --- | --- |
| `/lands deposit <金額> [土地名]` | 土地の資金（バンク）へ入金します。 |
| `/lands eco taxes` | 今後支払う必要のある税金の予定を確認します。 |
| `/lands eco upkeep` | 今後支払う必要のある維持費の予定を確認します。 |

## スポーン・移動

| コマンド | 説明 |
| --- | --- |
| `/lands setspawn` | 編集中の土地のスポーン地点を設定します。 |
| `/lands spawn [土地名]` | 土地のスポーン地点へテレポートします。 |
| `/lands rtp` | サーバーの設定で有効になっている場合、ランダムな場所へテレポートします。 |
| `/lands unstuck` | 土地の中に閉じ込められた場合に、近くの未保護の場所へ脱出します。 |
| `/lands confirmtp` | 安全確認が必要なテレポート先への移動を確定します。 |

## 国家（Nations）

Landsでは、複数の土地が集まって国家を結成できます。国家関連のコマンドは `/nations`（`/nation` でも可）から実行します。

| コマンド | 説明 |
| --- | --- |
| `/nations` または `/nations menu` | 国家メニューを開きます。 |
| `/nations create [名前]` | 新しい国家を作成します。 |
| `/nations invite <土地名>` | 国家に土地を招待します。 |
| `/nations kick <土地名>` | 国家から土地を除名します。 |
| `/nations leave` | 所属している国家から脱退します。 |

## 外交・戦争

外交・戦争に関するコマンドは、独立したコマンドではなく `/lands relations`・`/lands war ...`・`/nations war ...` の形で実行します。

| コマンド | 説明 |
| --- | --- |
| `/lands relations` | 他の土地との関係（同盟・敵対など）を管理します。 |
| `/lands war declare <土地名または国家名>` | 指定した相手に宣戦布告します。 |
| `/lands war spawn` | 戦争中のスポーン地点へテレポートします（該当の権限が必要です）。 |

:::tip[より詳しく知りたい場合]

- ロールごとの権限や招待の詳しい流れは、[メンバー・ロール管理](/lands/roles/) を確認してください。
- 外交・戦争の詳しい仕組みは、[国際関係・戦争](/lands/diplomacy/) を確認してください。
- 税金・維持費の仕組みは、[Lands作成・維持費](/lands/upkeep/) を確認してください。

:::
