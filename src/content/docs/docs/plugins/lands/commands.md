# Lands

**Lands** は、プレイヤーが土地を保護し、他のプレイヤーと集団・国家を運営するためのプラグインです。

## Landsとは

Landsでは、プレイヤーがチャンク単位で土地を保護し、他のプレイヤーをメンバーとして招待できます。GUIメニューから直感的に操作でき、土地の保護だけでなく、複数のプレイヤーが集まって集団や国家を形成し、外交や戦争を行うこともできます。

## 主な機能

- 土地の保護
- メンバー管理
- 権限・ロール管理
- 外交
- 戦争
- 維持費

## Landsの基本的な流れ

1. **土地を保護する**：`/lands claim` や専用のクレームツールを使い、自分の周囲のチャンクを土地として保護します。
2. **メンバーを招待する**：保護した土地に、他のプレイヤーをメンバーとして招待し、一緒に管理・利用できるようにします。
3. **ロールを設定する**：メンバーごとにロール（役職）を割り当て、できる操作を細かく制限します。
4. **集団・国家を運営する**：複数のプレイヤーで土地を運営し、必要に応じて他の集団・国家と外交関係を結んだり、戦争を行ったりします。
5. **維持費を管理する**：保護しているチャンク数などに応じて発生する維持費を、税収などでまかないます。
