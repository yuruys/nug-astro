**Lands** は、プレイヤーが土地を保護し、他プレイヤーと集団・国家を運営するためのプラグインです。

自分の建築物を荒らしから守ったり、仲間と一緒に村や国を発展させたり、他の国と同盟や戦争を行ったりと、コミュニティの中心となる仕組みです。

## 3つの規模感

Landsでは、土地の保護単位が3種類あります。

| 単位 | 概要 |
|---|---|
| **キャンプ** | 1日限定・無料の一時的な土地保護。他プレイヤーを招待できない |
| **集団 (Lands)** | メンバーを招待できる土地保護の基本単位。維持費が必要 |
| **国 (Nation)** | 複数の集団をまとめた上位組織。外交関係は国単位で統一される |

それぞれの詳しい条件（称号の条件、住民数、銀行残高など）は [基本的な仕組み](/docs/plugins/lands/) にまとめています。

## できること

- **土地の保護** — 自分や仲間の建築物を他人の破壊・盗難から守る
- **メンバー・ロール管理** — 招待、権限付与（Trust）、昇格・降格、サブエリアごとの権限設定
- **外交・戦争** — 他の集団や国と同盟・敵対関係を結び、宣戦布告して戦争を行う
- **維持費の管理** — チャンク単位での週次維持費を支払い、土地を維持する
- **便利機能** — 集団・国内チャット、共有ストレージ、チャンクマップなど
