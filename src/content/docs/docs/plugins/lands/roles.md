# メンバー・ロール管理

Landsでは、土地のメンバーに「ロール（役職）」を割り当て、ロールごとにできる操作を細かく設定できます。ここでは、デフォルトで用意されているロールと、ロールに紐づく権限（フラグ）についてまとめています。

## デフォルトのロール

土地を作成すると、初期状態で以下の4つのロールが用意されています。

| ロール | 説明 |
| --- | --- |
| Owner（オーナー） | 土地の作成者。すべての操作が可能な最上位のロールです。 |
| Admin（管理者） | オーナーに次ぐ強い権限を持つロールです。信頼できるメンバーにのみ付与することが推奨されています。 |
| Member（メンバー） | `/lands trust` で信頼されたプレイヤーに割り当てられる、標準的なロールです。 |
| Visitor（来訪者） | 信頼されていない、土地に立ち入っただけのプレイヤーに適用されるロールです。 |

これらに加えて、外交関係にあわせた特別なロールも用意されています。

| ロール | 説明 |
| --- | --- |
| Nation（国家） | 同じ国家に所属する土地のメンバーに適用される権限です。 |
| Ally（同盟） | 同盟関係にある土地のメンバーに適用される権限です。 |

## ロールのカスタマイズ

デフォルトの4ロールに加えて、土地ごとに独自のロールを追加することもできます。例えば「建築担当」「取引担当」のような役割を作り、それぞれに必要な権限だけを与える、といった運用が可能です。ロールの追加・編集は、`/lands` でメニューを開き、ロール設定の項目から行います。

## 権限（フラグ）の種類

ロールに設定できる権限は、大きく分けて2種類あります。

| 種類 | 説明 |
| --- | --- |
| アクションフラグ | ブロックの破壊・設置、モブへの攻撃など、実際のゲームプレイに関する操作を制御します。 |
| 管理フラグ | メンバーの招待、ロールの変更、税金の設定、宣戦布告など、土地の管理に関する操作を制御します。 |

### 代表的なアクションフラグ

| フラグ | 内容 |
| --- | --- |
| BLOCK_BREAK | ブロックを破壊できるか |
| BLOCK_PLACE | ブロックを設置できるか |
| ATTACK_PLAYER | 他のプレイヤーを攻撃できるか |
| ATTACK_ANIMAL | 動物を攻撃できるか |
| CONTAINER | チェストなどの収納を開けられるか |
| INTERACT | ボタンやレバー、ドアなどを操作できるか |

### 代表的な管理フラグ

| フラグ | 内容 |
| --- | --- |
| TRUST | プレイヤーを信頼（メンバーに追加）できるか |
| SET_ROLE | 他のメンバーのロールを変更できるか |
| CLAIM | 土地の保護範囲を広げられるか |
| UNCLAIM | 土地の保護を解除できるか |
| SET_FLAG | ロールのフラグを変更できるか |
| DECLARE_WAR | 他の土地・国家に宣戦布告できるか |

実際に設定できるフラグの種類や名称は、サーバーの設定（プラグインのバージョン）によって多少異なる場合があります。土地のメニューから、ロールごとに設定できるフラグの一覧を直接確認できます。

## 自然のフラグ（土地全体の設定）

ロールに紐づかない、土地全体に対する設定として「自然のフラグ」もあります。これはメンバーの役職に関係なく、土地単位で有効・無効を切り替えるものです。

| フラグ | 内容 |
| --- | --- |
| MONSTER_SPAWN | 土地内でモンスターが自然湧きするか |
| ANIMAL_SPAWN | 土地内で動物が自然湧きするか |
| FIRE_SPREAD | 土地内で火が燃え広がるか |
| LEAF_DECAY | 葉ブロックが自然に消滅するか |
| PLANT_GROWTH | 作物などの植物が自然に成長するか |

## ロールの設定方法

- **ロールを変更する**：`/lands setrole <プレイヤー名> <ロール名> [エリア]` で、指定したプレイヤーのロールを変更します。土地のメニューから、対象プレイヤーを左クリックで昇格・右クリックで降格することもできます。
- **オーナーを譲渡する**：`/lands setowner <プレイヤー名>` で、土地のオーナー権限そのものを譲渡します。ロール変更コマンドではオーナーの設定はできません。
- **フラグを切り替える**：土地のメニューから対象のロールを選び、フラグ設定の画面で個別にオン・オフを切り替えます。

:::tip[外交や維持費についても知りたい場合]

- 他の土地との関係については、[国際関係・戦争](/lands/diplomacy/) を確認してください。
- 税金や維持費の仕組みは、[Lands作成・維持費](/lands/upkeep/) を確認してください。
