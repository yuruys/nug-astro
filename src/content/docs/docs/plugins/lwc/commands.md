# LWC コマンド一覧

LWC（LWC Extended）で使用できるコマンドを、目的別にまとめています。多くのコマンドは、実行した後に対象のブロックをクリックすることで適用されます。

## 保護の作成

| コマンド | 説明 |
| --- | --- |
| `/cprivate [プレイヤー名/グループ名...]` | 対象をPrivate（自分専用）として保護します。プレイヤー名を続けて入力すると、そのプレイヤーとも共有できます。 |
| `/cpublic` | 対象をPublicとして保護します。誰でも使用できますが、破壊からは保護されます。 |
| `/cpassword <パスワード>` | 対象にパスワードを設定して保護します。パスワードを知っているプレイヤーは誰でも使用できます。 |
| `/cdonation [プレイヤー名/グループ名...]` | 対象を寄付用として保護します。誰でもアイテムを入れられますが、取り出せるのはオーナーだけです。 |
| `/cdisplay [プレイヤー名/グループ名...]` | 対象を展示用として保護します。中身を見ることはできますが、出し入れはできません。 |

グループを対象にする場合は、プレイヤー名の代わりに `g:グループ名` の形式で指定します。名前の前に `@` を付けると、そのプレイヤーに保護の管理権限（メンバーの追加など）も与えられます。

## 保護の管理

| コマンド | 説明 |
| --- | --- |
| `/cinfo` | クリックした対象の保護情報（オーナーや保護タイプなど）を確認します。 |
| `/cmodify <プレイヤー名/グループ名...>` | 既存の保護に対して、アクセスできるプレイヤー・グループを追加します。名前の前に `-` を付けると、そのプレイヤー・グループを削除できます。 |
| `/cremove` | クリックした対象の保護を解除します。 |
| `/cunlock <パスワード>` | パスワード保護された対象を、ログイン後に一度だけ解除（アンロック）します。 |
| `/climits` | 自分が作成できる保護の上限数を確認します。 |

## 便利なオプション

| コマンド | 説明 |
| --- | --- |
| `/cpersist` | 連続保護モードを切り替えます。オンにすると、以降クリックした対象すべてに直前と同じ保護が適用されます。 |
| `/cmagnet [on\|off]` | チェストに設定すると、周囲に落ちているアイテムを自動で吸い込むようになります。 |
| `/credstone [on\|off]` | ドアやトラップドアに設定すると、レッドストーンによる開閉を無効にできます。 |
| `/cautoclose [on\|off]` | ドアやトラップドアが、一定時間後に自動で閉まるように設定します。 |
| `/cnospam` | LWCからの通知メッセージ（「このドアは〇〇によってロックされています」など）の表示を抑制します。 |

## 管理者向けコマンド

サーバー管理者向けのコマンドです。使用には別途権限が必要です。

| コマンド | 説明 |
| --- | --- |
| `/lwc admin` | LWCの管理者向けメニューを開きます。 |
| `/lwc admin update` | LWCを最新バージョンへ更新します。 |
| `/cadmin` | 管理者権限で、他人の保護に対して操作を行います。 |

:::tip[LWCの基本的な仕組みを知りたい場合]

保護の種類や基本的な使い方については、[LWCとは](/lwc/) を確認してください。

:::
