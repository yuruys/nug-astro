# LWC

**LWC**（LWC Extended）は、チェストやかまど、ドアといったブロックを保護し、許可していないプレイヤーによる盗難や破壊を防ぐためのプラグインです。Boltと同様に、土地全体ではなく個々のブロックを対象に保護をかけます。

## LWCとは

LWCでは、チェストやドアなどの対象ブロックに「ロック」をかけることで、自分と許可したメンバー以外がその中身を使ったり、ブロック自体を壊したりできないようにします。設置するだけで自動的に保護される対象ブロックも多く、初心者でも手軽に利用できるのが特徴です。

## 主な機能

- チェスト・かまど・ドアなどのブロックの保護
- 爆発や外部からの破壊行為からの保護
- 自動保護（設置と同時にPrivate化）
- 手動保護・保護解除
- メンバーとの共有設定
- パスワードによる保護

## 保護の種類

| 種類 | 説明 |
| --- | --- |
| Private | 自分と、許可したメンバーのみが使用できる保護です。 |
| Public | 誰でも使用できますが、破壊は保護されているため防げます。 |
| Password | パスワードを知っているプレイヤーのみが使用できる保護です。 |

## 基本的な使い方

- **自動保護**：チェストやかまど、ドアなどの対象ブロックを設置すると、多くの場合そのままPrivateとして保護されます。
- **手動保護**：`/cprivate` を実行してから対象ブロックをクリックすると、Privateとして保護できます。
- **保護の解除**：`/cremove` を実行してから対象ブロックをクリックすると、自分がかけた保護を解除できます。
- **メンバーとの共有**：`/cprivate <プレイヤー名>` のように、コマンドの後にプレイヤー名を付けて実行すると、そのプレイヤーとチェストなどを共有できます。

:::tip[コマンドを知りたい場合]

LWCの具体的なコマンド一覧は、[コマンド一覧](/lwc/commands/) を確認してください。

:::
