# 就職・職業一覧

Jobsで就職できる職業と、それぞれの職業でお金・経験値を得られる主な行動をまとめています。

## 職業一覧

| 職業名 | 和名 | 主な収入源となる行動 |
| --- | --- | --- |
| Woodcutter | 木こり | 原木や葉ブロックの伐採 |
| Miner | 鉱夫 | 石材・鉱石の採掘 |
| Builder | 建築家 | ブロックの設置 |
| Digger | 掘削作業者 | 土・砂など、シャベルで掘れるブロックの採掘 |
| Farmer | 農家 | 作物の種まき・収穫、動物の繁殖や餌やり、羊の毛刈り、牛の乳しぼりなど |
| Hunter | 狩人 | モンスターや動物の討伐 |
| Explorer | 探検家 | 未到達のチャンクへの移動 |
| Crafter | 製作者 | アイテムのクラフト |
| Fisherman | 漁師 | 釣り |
| Weaponsmith | 鍛冶屋 | 武器・防具の作成や修理 |
| Brewer | 醸造師 | ポーションの醸造 |
| Enchanter | エンチャント師 | アイテムへのエンチャント付与 |

## 兼業について

Jobsでは、一度に複数の職業に就くことができます。ただし、同時に就ける職業の数や、組み合わせの制限（例：MinerとDiggerの兼業禁止など）はサーバーの設定によって異なります。実際に就ける職業数や制限については、ゲーム内で `/jobs browse` を確認するか、運営へお問い合わせください。

## 職業ごとの収入の仕組み

それぞれの職業には、対象となる行動の種類（アクションタイプ）が設定されています。代表的なものは以下のとおりです。

| アクションタイプ | 内容 |
| --- | --- |
| Break | 特定のブロックを破壊する |
| Place | 特定のブロックを設置する |
| Kill | 特定のMobを倒す |
| Fish | 釣りをする |
| Craft | 特定のアイテムをクラフトする |
| Smelt | かまどで精錬する |
| Brew | ポーションを醸造する |
| Enchant | アイテムにエンチャントを付与する |
| Repair | アイテムを修理する |

ブロックを設置した後に同じブロックを壊した場合など、一部の行動は報酬の対象外（ペナルティ）になることがあります。詳しい報酬額や対象ブロック・アイテムは、ゲーム内で `/jobs info <職業名>` から確認できます。

:::tip[基本的な使い方を知りたい場合]

就職・退職のコマンドなど、Jobsの基本的な使い方については、[Jobsとは](/jobs/) を確認してください。

:::
