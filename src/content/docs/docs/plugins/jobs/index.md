# Jobs

**Jobs** は、プレイヤーが「職業」に就き、その職業に応じた行動（ブロックの破壊・設置、Mobの討伐、釣り、クラフトなど）を行うことで、報酬とジョブ経験値を得られるプラグインです。

## Jobsとは

Jobsでは、木こりや鉱夫、農家など複数の職業が用意されており、プレイヤーは自分の好きな職業に就職できます。職業に応じた作業を行うと、お金とジョブ経験値が入り、経験値が貯まるとその職業のレベルが上がっていきます。レベルが上がるほど、1回の作業で得られる報酬や経験値の量も増えていきます。

## 主な機能

- 複数の職業への就職・転職・退職
- 職業に応じた作業に対するお金・経験値の獲得
- 職業レベル・ランクの成長
- 職業ごとの給与テーブルの確認
- 他のプレイヤーの就職状況の確認

## 職業ランク

職業にはレベルに応じたランクが設定されており、レベルが上がるほど熟練度の高いランクに進みます。

| ランク | レベル目安 |
| --- | --- |
| Rookie（新人） | 低レベル帯 |
| Apprentice（見習い） | やや低レベル帯 |
| Novice（未熟者） | 中レベル帯 |
| Craftsman（職人） | 中〜高レベル帯 |
| Journeyman（熟練した職人） | 高レベル帯 |
| Expert（名人） | 高レベル帯 |
| Master（達人） | 非常に高いレベル帯 |
| God（神） | 最高レベル帯 |

レベルが上がるほど、次のランクに必要な経験値も増えていきます。具体的なレベル基準や報酬額は、サーバーの設定によって異なります。

## 基本的な使い方

- **職業を探す**：`/jobs browse` で、就職できる職業の一覧とその内容を確認できます。
- **職業に就く**：`/jobs join <職業名>` で、指定した職業に就職します。
- **職業を辞める**：`/jobs leave <職業名>` で、指定した職業を退職します。
- **職業の詳細確認**：`/jobs info <職業名>` で、その職業の給与や経験値などの詳細を確認できます。

:::tip[職業一覧を知りたい場合]

各職業の詳しい内容については、[就職・職業一覧](/jobs/professions/) を確認してください。

:::
