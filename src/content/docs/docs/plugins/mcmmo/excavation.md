# Excavation - 掘削

**Excavation（掘削）** は、シャベルで土や砂などを掘ることに関するmcMMOのスキルです。レベルが上がるほど、アビリティの持続時間が延び、レアなアイテムも見つけやすくなります。

## ギガドリルブレイカー

採掘速度の上昇に加えて、ドロップ率が3倍、獲得経験値が3倍になるアビリティです。レベルが上がるほど持続時間が延長されます。

| レベル | 持続時間 |
| --- | --- |
| Lv.50 | 3秒 |
| Lv.100 | 4秒 |
| Lv.250 | 7秒 |
| Lv.500 | 12秒 |

## 宝探し

土・砂・砂利などを掘った際に、低確率でレアアイテムが手に入るアビリティです。ドロップしたアイテムに応じた経験値も獲得できます。掘るブロックの種類によって、出現するアイテムと確率が異なります。
