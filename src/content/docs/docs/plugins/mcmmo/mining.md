# Mining - 採掘

**Mining（採掘）** は、鉱石や石を掘ることに関するmcMMOのスキルです。レベルが上がるほど、採掘速度や採取量が向上していきます。

## スーパーブレーカー

採掘速度が大幅に上昇し、ドロップ量が3倍になるアビリティです。後述のドロップ2倍と重複すると、鉱石の入手量がさらに増えます。レベルが上がるほど持続時間が延長されます。

| 採掘レベル | 持続時間 |
| --- | --- |
| Lv.50 | 3秒 |
| Lv.100 | 4秒 |
| Lv.200 | 6秒 |
| Lv.300 | 8秒 |
| Lv.400 | 10秒 |
| Lv.500 | 12秒 |
| Lv.600 | 14秒 |
| Lv.700 | 16秒 |
| Lv.800 | 18秒 |
| Lv.900 | 20秒 |
| Lv.1000 | 22秒（最大） |

## ドロップ2倍

採掘レベルが上がるごとに、鉱石を掘った際にアイテムが2個ドロップする確率が上がるアビリティです（NEarthサーバーでは、金鉱石に対しては無効です）。

| 採掘レベル | ダブルドロップ率 |
| --- | --- |
| Lv.0 | 0% |
| Lv.500 | 50% |
| Lv.1000 | 100%（最大） |

## ドロップ3倍

スキルレベル1000で解放されるアビリティです。採掘レベルが上がるごとに、鉱石を掘った際にアイテムが3個ドロップする確率が上がります（NEarthサーバーでは、金鉱石に対しては無効です）。

:::
