# Repair - 修理

**Repair（修理）** は、鉄ブロックを「金床」代わりにして、道具や防具を修理できるmcMMOのスキルです。レベルが上がるほど、修理できる耐久値や、エンチャントを維持できる確率が上昇していきます。

## 修理

鉄ブロックを設置し、修理したい道具や防具を持った状態で右クリックすると、その装備と同じ素材（鉄装備なら鉄インゴットなど）を1つ消費して修理できます。修理で得られる経験値は、回復した耐久値の量に応じて増えます。

## 修理の達人

修理時に回復する耐久値が増加するパッシブ効果です。レベルが上がるほど、回復量が増えていきます。

## スーパーリペア

修理の効果が2倍になる（通常の2倍の耐久値を回復する）チャンスを得るパッシブ効果です。レベルが上がるほど発動確率が上昇します。

| レベル | 発動確率 |
| --- | --- |
| Lv.400 | 40% |
| Lv.1000 | 100%（最大） |

## アルケインフォージング

エンチャントが付いた装備を修理した際に、エンチャントをそのまま維持できるかどうかを決めるパッシブ効果です。レベルが上がるほど「維持できる確率」が上昇し、「エンチャントが弱まる確率」は下がっていきます。

| レベル | 維持できる確率 | 弱まる確率 |
| --- | --- | --- |
| Lv.100 | 10% | 75% |
| Lv.500 | 40% | 30% |
| Lv.1000 | 60% | 10% |

上記のいずれにも当てはまらなかった場合、エンチャントは失われてしまいます。

:::tip[mcMMO全体の仕組みを知りたい場合]

mcMMOの基本的な仕組みや、他のスキルについては、[mcMMOとは](/docs/mcmmo/) を確認してください。

:::
