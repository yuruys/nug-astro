# Acrobatics - アクロバティック

**Acrobatics（アクロバティック）** は、落下ダメージの軽減や、攻撃の回避に関するmcMMOのスキルです。レベルが上がるほど、各アビリティの成功率が上昇していきます。

## 受け身

落下時にダメージを大幅に軽減するアビリティです。レベルが上がるほど、成功率が上昇します。

| レベル | 成功率 |
| --- | --- |
| Lv.0 | 0% |
| Lv.500 | 50% |
| Lv.1000 | 100% |

## 受け身+スニーク

受け身の強化版で、通常の2倍のダメージを軽減します。落下中にスニークすることで発動し、レベルが上がるほど成功率が上昇します。

| レベル | 成功率 |
| --- | --- |
| Lv.0 | 0% |
| Lv.500 | 100% |
| Lv.1000 | 200% |

## 躱す

攻撃で受けるダメージを半減させるアビリティです。クリーパーの爆発やスケルトンの矢などが対象になります。レベルが上がるほど成功率が上昇します。

| レベル | 成功率 |
| --- | --- |
| Lv.0 | 0% |
| Lv.500 | 10% |
| Lv.1000 | 20% |

:::tip[mcMMO全体の仕組みを知りたい場合]

mcMMOの基本的な仕組みや、他のスキルについては、[mcMMOとは](/mcmmo/) を確認してください。

:::
