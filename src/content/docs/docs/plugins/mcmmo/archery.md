# Archery - 弓

**Archery（弓）** は、弓を使った戦闘に関するmcMMOのスキルです。レベルが上がるほど、与えるダメージや、各アビリティの発動確率が上昇していきます。

## スキルショット

弓で与えるダメージが増加するアビリティです。スキルレベル50ごとに10%ずつ増加し、レベル1000で最大200%になります。

| レベル | 追加ダメージ |
| --- | --- |
| Lv.50 | 10% |
| Lv.100 | 20% |
| Lv.150 | 30% |
| Lv.200 | 40% |
| Lv.250 | 50% |
| Lv.300 | 60% |
| Lv.350 | 70% |
| Lv.400 | 80% |
| Lv.450 | 90% |
| Lv.500 | 100% |
| Lv.550 | 110% |
| Lv.600 | 120% |
| Lv.650 | 130% |
| Lv.700 | 140% |
| Lv.750 | 150% |
| Lv.800 | 160% |
| Lv.850 | 170% |
| Lv.900 | 180% |
| Lv.950 | 190% |
| Lv.1000 | 200%（最大） |

## 矢回収

モブを倒した際に、一定確率で矢が戻ってくるアビリティです。確率は「レベル×0.0001」で計算され、レベルが上がるほど確率が上昇します。

| レベル | 確率 |
| --- | --- |
| Lv.100 | 10% |
| Lv.500 | 50% |
| Lv.1000 | 100%（最大） |

## 幻惑

一定確率で対象（プレイヤーのみ）に6秒間の吐き気効果を与え、さらに4ダメージを追加で与えるアビリティです。レベルが上がるほど発動確率が上昇します。

| レベル | 確率 |
| --- | --- |
| Lv.100 | 5% |
| Lv.500 | 25% |
| Lv.1000 | 50%（最大） |

:::tip[mcMMO全体の仕組みを知りたい場合]

mcMMOの基本的な仕組みや、他のスキルについては、[mcMMOとは](/mcmmo/) を確認してください。

:::
