# Herbalism - 農業

**Herbalism（農業）** は、作物や植物の収穫に関するmcMMOのスキルです。レベルが上がるほど、収穫効率が良くなったり、満腹度の回復量が増えたりします。

## グリーンテラ

スキルレベル50で解放されるアビリティです。収穫量が3倍になり、さらに高確率で自動的に苗が植え直されます。

## ダブルドロップ

作物を収穫した際に、アイテムが2個ドロップする確率が上がるアビリティです。レベルが上がるほど発動確率が上昇します。

| レベル | 発動確率 |
| --- | --- |
| Lv.100 | 10% |
| Lv.500 | 50% |
| Lv.1000 | 100%（最大） |

## グリーンサム

収穫と同時に、自動で作物を植え直してくれるアビリティです。レベルが上がるほど成功率が上昇します。

| レベル | 発動確率 |
| --- | --- |
| Lv.100 | 10% |
| Lv.500 | 50% |
| Lv.1000 | 100%（最大） |

## 農家の食事

農業系の食料を食べたときの満腹度の回復量が増加するパッシブ効果です。スキルレベルが上がるほど、回復量も増えていきます。
