# Maces - メイス

**Maces（メイス）** は、Minecraft 1.21で追加された武器「メイス」を使った戦闘に関するmcMMOのスキルです。他のスキルと比べて新しく追加されたスキルで、メイス本来のスマッシュアタック（落下しながらの攻撃）を活かして戦います。

## クラッシュ

レベルが上がるごとに、メイスでのダメージが増加していくパッシブ効果です。

## クリップル

プレイヤー・モブを問わず、攻撃を命中させた相手に鈍化（スロウネス）効果を与えるアビリティです。

:::tip[mcMMO全体の仕組みを知りたい場合]

mcMMOの基本的な仕組みや、他のスキルについては、[mcMMOとは](/docs/mcmmo/) を確認してください。

:::
