# Unarmed - 素手

**Unarmed（素手）** は、何も持たない状態での格闘に関するmcMMOのスキルです。レベルが上がるほど、素手での攻撃力や、各種アビリティの発動確率が向上していきます。

## ベルセルク

素手の状態で右クリックして構え、その直後に対象（モブ・プレイヤー・弱いブロック）を殴ることで発動するアビリティです。発動中は与えるダメージが50%増加し、土や砂、雪、ガラス、葉ブロックなどの柔らかいブロックを瞬時に破壊できるようになります。レベルが上がるほど持続時間が延長されます。

## 鋼の腕

素手での通常攻撃に、追加ダメージを加えるパッシブ効果です。レベルが上がるほど追加ダメージが増加していきます。

| レベル | 追加ダメージ |
| --- | --- |
| Lv.50 | +4 |
| Lv.100 | +5 |
| Lv.150 | +6 |
| Lv.200 | +7 |
| Lv.250 | +8（最大） |

## 武装解除

他のプレイヤーに素手で攻撃を命中させた際、一定確率で相手が手に持っているアイテムを落とすアビリティです。レベルが上がるほど発動確率が上昇します。

| レベル | 発動確率 |
| --- | --- |
| Lv.100 | 10% |
| Lv.500 | 30% |
| Lv.1000 | 33%（最大） |

## アイアングリップ

相手からの「武装解除」を防ぐ、カウンター用のパッシブ効果です。レベルが上がるほど、防げる確率が上昇します。

## 矢逸らし

素手の状態で矢を受けた際に、一定確率で矢を無害化して弾くアビリティです。レベルが上がるほど発動確率が上昇します。

| レベル | 発動確率 |
| --- | --- |
| Lv.100 | 5% |
| Lv.500 | 25% |
| Lv.1000 | 50%（最大） |

## 素手 限界突破

体力の多い、タフな敵に対して与えるダメージが増加するパッシブ効果です。
