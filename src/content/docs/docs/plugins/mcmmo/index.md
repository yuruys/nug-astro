# mcMMO

**mcMMO** は、木を切ったり、鉱石を掘ったり、モンスターを倒したりといった日常的な行動にレベルという概念を追加し、レベルに応じて多彩なスキル・アビリティが使えるようになるプラグインです。RPGのような成長要素を、通常のサバイバルプレイにそのまま取り入れられるのが特徴です。

## mcMMOとは

mcMMOでは、採掘・伐採・戦闘・釣りなど、行動の種類ごとに個別の「スキル」が用意されています。各スキルには専用の経験値があり、対応する行動を行うたびに経験値が貯まってレベルが上がっていきます。レベルが上がるほど、収穫量が増えたり、特殊な能力（アビリティ）が使えるようになったりします。

## 主な機能

- 行動ごとに独立したスキルレベルの成長
- レベルに応じたアビリティ（特殊能力）の解放
- 全スキルの合計値である「パワーレベル」
- パーティを組んで経験値を共有する機能
- `/mcstats` などによる自分のスキル情報の確認

## スキル一覧

mcMMOには、大きく分けて「採取系」と「戦闘系」のスキルがあります。それぞれのスキルについて、簡単に説明します。

### 採取系スキル

| スキル | 簡単な説明 |
| --- | --- |
| [採掘](/mcmmo/mining/) | 鉱石や石を掘るスキルです。レベルが上がると、鉱石からの採取量が増えたり、まとめて掘れるアビリティが使えるようになったりします。 |
| [木こり](/mcmmo/woodcutting/) | 斧で木を切るスキルです。レベルが上がると、丸太を多く入手できるようになったり、木を一気に伐採できるアビリティが使えるようになったりします。 |
| [農業](/mcmmo/herbalism/) | 作物や植物を収穫するスキルです。レベルが上がると、収穫量が増えたり、自動で種をまき直すアビリティが使えるようになったりします。 |
| [掘削](/mcmmo/excavation/) | シャベルで土や砂を掘るスキルです。レベルが上がると、掘った際にレアなアイテムが見つかりやすくなります。 |
| [釣り](/mcmmo/fishing/) | 釣りをするスキルです。レベルが上がると、レアな釣果が出やすくなったり、モンスターを釣り上げて一撃で倒せるようになったりします。 |

### 戦闘系スキル

| スキル | 簡単な説明 |
| --- | --- |
| [剣](/mcmmo/swords/) | 剣を使って戦うスキルです。レベルが上がると、出血効果を与えたり、相手の攻撃を受け流したりできるようになります。 |
| [斧](/mcmmo/axes/) | 斧を武器として戦うスキルです。レベルが上がると、大ダメージを与えたり、相手の防具を素早く削ったりできるようになります。 |
| [弓](/mcmmo/archery/) | 弓を使って戦うスキルです。レベルが上がると、与えるダメージが増加します。 |
| [アクロバティック](/mcmmo/acrobatics/) | 落下やダメージ回避に関するスキルです。レベルが上がると、落下ダメージを軽減したり、攻撃を受け流したりしやすくなります。 |

:::tip[各スキルの詳しい仕様を知りたい場合]

各スキルの詳しいアビリティや、レベルアップの条件については、それぞれのスキルページを確認してください。

:::
