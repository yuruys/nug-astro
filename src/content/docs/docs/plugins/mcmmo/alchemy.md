# Alchemy - 錬金術

**Alchemy（錬金術）** は、醸造台でのポーション作りに関するmcMMOのスキルです。レベルが上がるほど、醸造速度が上がったり、バニラにはない特殊なポーションが作れるようになったりします。

## 経験値の入手方法

醸造台でポーションを作ることで経験値が入ります。醸造台にホッパーで材料を自動投入した場合は経験値が入らないため、必ず自分の手でアイテムを入れる必要があります。

## カタリシス

醸造にかかる時間を短縮するパッシブ効果です。スキルレベル100で解放され、レベルが上がるほど速度が上昇し、レベル1000で最大4倍の速さになります。

| レベル | 醸造速度 |
| --- | --- |
| Lv.100 | 解放（等倍） |
| Lv.500 | 約2倍 |
| Lv.1000 | 4倍（最大） |

## コンコクション

通常のMinecraftでは作れない、特殊なポーションを醸造できるようになるパッシブ効果です。解放されるポーションの種類は、以下のようにランクごとに分かれています。

| ランク | 主な内容 |
| --- | --- |
| ランク1 | 火薬玉、腐った目、ガストの涙など、バニラのポーション材料に対応 |
| ランク2 | ニンジンを使った「俊敏のポーション（採掘速度アップ）」、スライムボールを使った「鈍化のポーション」 |
| ランク3 | クォーツを使った「衝撃吸収のポーション」、ウサギの足を使った「跳躍のポーション」 |
| ランク4 | リンゴを使った「体力増強のポーション」、腐った肉を使った「空腹のポーション」 |
| ランク5 | 茶色いキノコを使った「吐き気のポーション」、イカスミを使った「盲目のポーション」 |
| ランク6 | シダを使った「満腹度回復のポーション」 |
| ランク7 | 毒のジャガイモを使った「衰弱のポーション」 |
| ランク8 | 金のリンゴを使った「耐性のポーション」 |

錬金術のレベルが対応するランクに達していないと、これらの特殊な材料は醸造台に入れることができません。また、名前を付けたアイテムは特殊なポーションの材料として使用できず、カタリシスによる速度上昇も適用されません。
