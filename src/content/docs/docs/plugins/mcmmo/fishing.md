# Fishing - 釣り

**Fishing（釣り）** は、釣りに関するmcMMOのスキルです。レベルが上がることで、レアなアイテムを釣り上げやすくなったり、モブから直接ドロップを得られるようになったりします。

## シェイク

スキルレベル15以上で解放されるアビリティです。釣竿でモブを引っ掛けると、そのモブを倒したときと同じアイテムがドロップします。

## トレジャーハント

スキルレベル10以上で解放されるアビリティです。釣りで宝物（レアアイテム）が釣れる確率が上がります。レアリティのランクが上がるほど、より貴重なアイテムが手に入りやすくなります。

## アイスフィッシング

氷に向かって釣竿を投げ入れると、氷に穴が空いて釣りができるようになるアビリティです。

## 釣りの達人

スキルレベル15以上で解放されるアビリティです。ボートに乗っている状態だと、アイテムが釣れやすくなります。

## 漁師の食事

魚を食べた際の満腹度の回復量が増加するパッシブ効果です。

## マジックハンター

エンチャントが付いたアイテムが釣れやすくなるパッシブ効果です。
