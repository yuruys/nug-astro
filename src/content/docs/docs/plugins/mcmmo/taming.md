# Taming - 調教

**Taming（調教）** は、オオカミやヤマネコなどのペットを戦闘の頼れる仲間にするmcMMOのスキルです。ペットが敵にダメージを与えるたびに経験値が入り、レベルが上がるほどペットが強化されていきます。

## 使役

骨（オオカミ）や生魚（ヤマネコ）などを10個持ってスニークしながら左クリックすると、その場にペットを呼び出せるアビリティです。

## 獣の知識

ペットに向かって骨を持った状態で左クリックすると、そのペットの飼い主やHPなどの情報を確認できるアビリティです。

## ゴア

ペットが攻撃を命中させた際に、一定確率で相手に出血効果を与えるアビリティです。レベルが上がるほど発動確率が上昇します。

| レベル | 発動確率 |
| --- | --- |
| Lv.500 | 50% |
| Lv.1000 | 100%（最大） |

## ファストフードサービス

スキルレベル50で解放されるアビリティです。ペットが攻撃を命中させた際に、一定確率で自身のHPを回復します。

## 環境への適応

スキルレベル100で解放されるパッシブ効果です。ペットがサボテンや溶岩などの危険な場所に近づくと、自動的に飼い主のそばへワープします。また、落下ダメージを受けなくなります。

## 厚い毛皮

スキルレベル250で解放されるパッシブ効果です。ペットが受けるダメージを軽減し、さらに火に対する耐性を得ます。

## ホーリーハウンド

スキルレベル375で解放されるパッシブ効果です。ペットが毒や呪いなどの負の効果を受けたときに、逆にHPを回復するようになります。

## ショックプルーフ

スキルレベル500で解放されるパッシブ効果です。ペットが受ける爆発ダメージを軽減します。

## 鋭い爪

スキルレベル750で解放されるパッシブ効果です。ペットの攻撃力に追加ダメージが加わります。
