# Sword - 剣

**Sword（剣）** は、剣を使った戦闘に関するmcMMOのスキルです。レベルが上がるほど、アビリティの持続時間や成功率、ダメージが向上していきます。

## セレーションストライク

発動すると、範囲（AOE）ダメージを与え、さらに相手を出血させる可能性があるアビリティです。レベルが上がるほど持続時間が延長されます。

| レベル | 持続時間 |
| --- | --- |
| Lv.50 | 3秒 |
| Lv.100 | 4秒 |
| Lv.250 | 7秒 |
| Lv.500 | 12秒 |

## 破裂

出血状態になると、毎秒2回、非致死性のダメージを受け続けます。このダメージは防具では軽減されません。

## カウンター攻撃

攻撃を受けた際に、そのダメージの一部を相手に反射させるアビリティです。レベルが上がるほど成功率が上昇します。

## 剣 限界突破

体力の多い、タフな敵に対して与えるダメージが増加するパッシブ効果です。
