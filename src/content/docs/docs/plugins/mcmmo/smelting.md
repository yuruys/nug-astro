# Smelting - 精錬

**Smelting（精錬）** は、かまどでの精錬に関するmcMMOのスキルです。他のスキルと異なり、Smeltingは「採掘」と「修理」の子スキルとして扱われ、この2つのスキルレベルの平均値が、そのままSmeltingのレベルになります。単独でレベルを上げることはできません。

## フューエルエフィシエンシー

かまどで使う燃料の燃焼時間を延長するパッシブ効果です。レベルが上がるほど倍率が上昇し、レベル1000で最大4倍になります。

| レベル | 燃焼時間の倍率 |
| --- | --- |
| Lv.250 | 約1.75倍 |
| Lv.500 | 約2.5倍 |
| Lv.1000 | 4倍（最大） |

## セカンドスメルト

鉱石を精錬した際に、一定確率でインゴットがもう1つ手に入るアビリティです。レベルが上がるほど発動確率が上昇します。

| レベル | 発動確率 |
| --- | --- |
| Lv.500 | 25% |
| Lv.1000 | 50%（最大） |

## バニラXPブースト

鉄鉱石や原木、砂など、かまどで精錬・焼成する際に得られる経験値が増加するパッシブ効果です。レベルが上がるほど倍率が上昇していきます。

## フラックスマイニング

耐久値が満タンのつるはしをかまどに入れると、「フラックスピッケル」に変化します。フラックスピッケルを装備して鉱石を採掘すると、一定確率でその場でインゴットに変換された状態で入手できます（採掘レベル250以上が目安です）。

:::tip[mcMMO全体の仕組みを知りたい場合]

mcMMOの基本的な仕組みや、他のスキルについては、[mcMMOとは](/docs/mcmmo/) を確認してください。採掘・修理については、それぞれ[Mining - 採掘](/docs/mcmmo/mining/)・[Repair - 修理](/docs/mcmmo/repair/)を確認してください。
