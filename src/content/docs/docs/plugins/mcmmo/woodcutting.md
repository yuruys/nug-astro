# Woodcutting - 木こり

**Woodcutting（木こり）** は、斧を使った木の伐採に関するmcMMOのスキルです。レベルが上がるほど、まとめて伐採できるアビリティの持続時間が延びたり、ドロップ率が上がったりします。

## ツリーフェラー

原木と葉ブロックを一括で破壊できるアビリティです。レベルが上がるほど持続時間が延長されます。ただし、斧の耐久値を大量に消費するため、耐久値が足りない状態で発動すると爆発が起き、自分がダメージを受けてしまいます。

## リーフブロワー

斧を使うと、葉ブロックが一瞬で消えるアビリティです。

## 収穫材

リーフブロワーで葉ブロックを消しながら木を伐採する際に、一定確率でドロップ量が2倍になるアビリティです。
