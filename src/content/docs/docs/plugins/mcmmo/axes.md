# Axes - 斧

**Axes（斧）** は、斧を武器として使う戦闘に関するmcMMOのスキルです。レベルが上がるほど、アビリティの威力や発動確率、持続時間が向上していきます。

## スカルスプリッター

範囲（AOE）ダメージを与えるアビリティです。レベルが上がるほど、効果の持続時間が延長されます。

| レベル | 持続時間 |
| --- | --- |
| Lv.50 | 3秒 |
| Lv.100 | 4秒 |
| Lv.250 | 7秒 |
| Lv.500 | 12秒 |

## アーマーインパクト

防具を粉砕する威力で攻撃し、相手の防具耐久値を2倍消耗させるアビリティです。レベルが上がるほど発動確率が上昇します。

| レベル | 発動確率 |
| --- | --- |
| Lv.0 | 0% |
| Lv.100 | 10% |
| Lv.250 | 25% |
| Lv.500 | 50% |
| Lv.750 | 75% |
| Lv.1000 | 100% |

## クリティカルストライク

一定確率で、斧の通常攻撃にクリティカル（通常ダメージの0.5倍の追加ダメージ）が発生するアビリティです。レベルが上がるほど発動確率が上昇します。

## Axe Mastery

レベルが上がるほど、斧そのものの攻撃力が上昇するパッシブ効果です。

| レベル | 追加ダメージ |
| --- | --- |
| Lv.100 | +2 |
| Lv.250 | +5 |
| Lv.500 | +10 |
| Lv.1000 | +20 |

## グレーターインパクト

追加ダメージ+2と、強いノックバックを同時に与えるアビリティです。レベルが上がるほど発動確率が上昇します。

| レベル | 発動確率 |
| --- | --- |
| Lv.0 | 0% |
| Lv.100 | 5% |
| Lv.500 | 25% |
| Lv.1000 | 50% |
