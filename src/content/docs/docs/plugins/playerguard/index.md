# PlayerGuard

**PlayerGuard** は、金の斧を使って選択した範囲を保護できるプラグインです。範囲内でのブロック破壊・設置やPvPなどを、権限として細かく設定できます。

## PlayerGuardとは

PlayerGuardでは、金の斧で2点を選択し、その範囲を1つの保護領域として登録します。保護領域には所有者とメンバーを設定でき、メンバー以外のプレイヤーに対しては、ブロックの破壊・設置やPvPなど、さまざまな行動を許可・拒否で細かく制御できます。

## 主な機能

- 範囲選択による土地の保護
- 保護領域ごとの権限（フラグ）設定
- メンバーの追加・削除
- 保護領域の情報確認
- 保護領域の移管（譲渡）
- プレイ時間に応じた保護制限（保護できる広さ）の増加

## 基本的な使い方

1. **範囲を選択する**：金の斧を右クリックして、保護したい範囲の一点目（始点）と二点目（終点）を選択します。
2. **保護する**：範囲を選択した状態で `/claim` を実行すると、保護領域が作成されます。
3. **権限を設定する**：`/flags` を実行すると、ブロックの破壊・設置やPvPなど、メンバー以外に対する権限をクリックで切り替えられます。
4. **メンバーを管理する**：`/playerguard add <プレイヤー名>` でメンバーを追加できます。メンバーは保護領域内の権限設定を無視して自由に行動できます。
5. **保護を解除する**：保護した領域に入った状態で `/disclaim` を実行すると、保護を解除できます。

:::tip[コマンドを知りたい場合]

実際のコマンドの詳しい使い方は、[コマンド一覧](/playerguard/commands/) を確認してください。

:::
