# QuickShop

**QuickShop** は、チェストを設置するだけで、コマンドをほとんど使わずにお店（ショップ）を作れるプラグインです。売りたいアイテムを手に持ってチェストを叩き、価格を入力するだけで、誰でも簡単に販売・買取のお店を開くことができます。

## QuickShopとは

QuickShopでは、チェストの上に看板のようなショップ表示が作られ、そこに書かれた価格を見て、他のプレイヤーがそのチェストを操作するだけで売買が成立します。お店を開く側も利用する側も、複雑なコマンドを覚える必要がほとんどないのが特徴です。

## 主な機能

- チェストを使った販売・買取ショップの作成
- クリック操作だけで完結する売買
- 在庫の自動管理
- エンチャント本やポーションなど、特殊なアイテムの売買
- 両替（売買両対応）ショップの作成（ダブルチェスト使用時）
- ショップの店主変更・在庫無制限化などの管理コマンド

## 基本的な使い方

1. **チェストを設置する**：お店にしたい場所にチェストを置きます。
2. **アイテムを持って叩く**：売りたい（または買い取りたい）アイテムを手に持った状態で、設置したチェストを左クリックします。
3. **価格を入力する**：チャット欄に価格を入力して送信すると、その価格でお店が作成されます。
4. **在庫を入れる**：販売用のお店であれば、チェストにアイテムを補充しておきます。買取用のお店であれば、支払いに使うお金や、受け取る在庫スペースを確保しておきます。
5. **取引する**：他のプレイヤーは、そのチェストをクリックし、購入・売却する個数をチャット欄に入力するだけで取引が完了します。

:::tip[コマンドを知りたい場合]

ショップの種類の切り替えや管理に使えるコマンドは、[コマンド一覧](/quickshop/commands/) を確認してください。

:::
