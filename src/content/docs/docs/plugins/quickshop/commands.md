# QuickShop コマンド一覧

QuickShopは、基本的な売買であればコマンドを一切使わずに利用できます。ここでは、ショップの種類変更や管理など、必要に応じて使うコマンドをまとめています。コマンドは `/qs` または `/quickshop`（サーバーによっては `/shop`）から実行します。

## ショップの作成・削除

| コマンド | 説明 |
| --- | --- |
| チェストを設置してアイテムで叩く | 手に持ったアイテムでチェストを叩き、価格を入力するだけでショップを作成できます（通常はコマンド不要です）。 |
| `/qs create [アイテム]` | クリック操作を使わず、コマンドでショップを作成します。 |
| `/qs supercreate` | 保護プラグインのチェックを無視してショップを作成します（管理者向け）。 |
| ショップを見ながらチェストを破壊 | ショップを削除します。 |

## ショップの種類・価格の変更

| コマンド | 説明 |
| --- | --- |
| `/qs buy` | 見ているショップを「買取（購入）専用」に変更します。 |
| `/qs sell` | 見ているショップを「販売専用」に変更します。 |
| `/qs price <金額>` | 見ているショップの価格を変更します。 |
| `/qs unlimited` | 見ているショップの在庫を無制限にします（管理者向け）。 |
| `/qs size <個数>` | まとめ売買の個数（バルクサイズ）を変更します。サーバー設定で有効になっている場合のみ使用できます。 |
| `/qs currency <通貨名>` | ショップで使用する通貨を指定します（対応する経済プラグインが必要です）。 |

## 所有者・スタッフの管理

| コマンド | 説明 |
| --- | --- |
| `/qs setowner <プレイヤー名>` | 見ているショップの店主を変更します。 |
| `/qs staff add <プレイヤー名>` | 見ているショップにスタッフを追加します。 |
| `/qs staff del <プレイヤー名>` | 見ているショップからスタッフを削除します。 |
| `/qs staff list` | 見ているショップのスタッフ一覧を表示します。 |
| `/qs staff clear` | 見ているショップのスタッフをすべて削除します。 |

## 検索・情報確認

| コマンド | 説明 |
| --- | --- |
| `/qs find <アイテム名>` | 指定した名前で始まるアイテムを扱っている、最も近いショップを検索します。 |
| `/qs info` | QuickShopの情報を表示します。 |

## 在庫の管理

| コマンド | 説明 |
| --- | --- |
| `/qs refill <個数>` | 見ているショップの在庫を補充します（権限が必要です）。 |
| `/qs empty` | 見ているショップの在庫をすべて空にします（権限が必要です）。 |
| `/qs clean` | 在庫が0のショップをまとめて削除します。 |
| `/qs cleanghost` | データ上は存在するものの、実際には壊れているショップを削除します。 |

## 管理者向けコマンド

サーバー管理者向けのコマンドです。使用には別途権限が必要です。

| コマンド | 説明 |
| --- | --- |
| `/qs debug` | デバッグモードを切り替えます。 |
| `/qs paste` | トラブルシューティング用の情報をまとめて出力します。 |
| `/qs export` | すべてのショップデータをファイルへ書き出します（コンソール専用）。 |
| `/qs recovery` | 書き出したファイルからショップデータを復元します（コンソール専用。既存データを上書きする可能性があるため注意が必要です）。 |
| `/qs purge` | 古いショップを一括整理します（サーバー設定でpurge機能が有効な場合のみ）。 |

:::tip[基本的な使い方を知りたい場合]

ショップの基本的な作り方・使い方については、[QuickShopとは](/quickshop/) を確認してください。

:::
