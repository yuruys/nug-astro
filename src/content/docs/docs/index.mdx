## Wikiの使い方

NUGBASEでは、情報を大きく3つに分けています。

:::tip[仕様を知りたいとき]

プラグインの機能やコマンド、権限などを調べたい場合は、**Wiki**を利用してください。

:::

:::note[サーバーごとの違いを知りたいとき]

NEarth・Life・Choなど、サーバー固有の仕様を確認したい場合は、[**サーバー情報**](/docs/servers/)を確認してください。

:::

:::caution[実際の遊び方を知りたいとき]

「お金を稼ぎたい」「土地を作りたい」「ショップを開きたい」など、目的から調べたい場合は、[**攻略**](/guide/)をご覧ください。

:::

[攻略を見る →](/guide/)

## NUGBASEについて
テスト
NUGBASEは、Nekozouneko Serverの情報をプレイヤー目線で整理する非公式ガイドサイトです。

Wikiでは仕様・コマンド・プラグインなどの情報を整理し、攻略では実際のプレイに役立つ情報を扱っています。

:::note

掲載されている情報は変更される場合があります。最新の仕様と異なる場合は、ゲーム内の情報や公式情報もあわせて確認してください。

:::
