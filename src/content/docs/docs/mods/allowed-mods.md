# 使用許可MOD一覧

**Nekozouneko Server** では、一部のクライアントMODの使用が許可されています。ここでは、軽量化・視覚効果・レシピ表示・UI・チャット・音響・アニメーションなど、カテゴリ別に使用許可MODをまとめています。

## 使用許可MODとは

使用許可MODは、ゲームプレイに有利不利をもたらさない範囲で、快適性や視認性を向上させる目的で許可されているMODです。以下の一覧にないMODを使用したい場合は、事前に運営へ確認することをおすすめします。

## 軽量化

| MOD名 | 役割 |
| --- | --- |

| Entity Culling | 視界に入らないモブやエンティティの描画をスキップして軽量化する |

| VulkanMod | 描画規格をVulkanに置き換え、環境によってはFPSを向上させる |

## レシピ表示・情報確認

| MOD名 | 役割 |
| --- | --- |
| EMI | レシピのツリー表示やアイテム検索が見やすい、整理されたレシピ確認MOD |
