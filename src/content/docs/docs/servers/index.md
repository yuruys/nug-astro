# サーバー紹介

Nekozouneko Serverには、遊び方の異なる複数のサーバーが用意されています。ここでは、その中でも代表的な3つのサーバー「超サーバー」「ライフサーバー」「NEarthサーバー」の特徴をまとめています。

## 超サーバー

**便利機能が満載の、腰を据えて遊べるサバイバルサーバーです。**

mcMMOによるスキル・アビリティや、ペットを飼いならせる要素など、通常のサバイバルにはない便利さが詰め込まれています。毎月1日にはメインワールドが新しいワールドへ切り替わり、いつ参加しても新鮮な気持ちで楽しめます。

- 月替わりのワールド更新（エンダーチェスト・mcMMO・ペットの情報は引き継ぎ）
- 通常のサバイバルにはない自然生成物
- 初期スポーン周辺の区画分け（25×25の区画が144個）
- mcMMOによるスキル・アビリティ

:::tip[詳しく知りたい場合]

[超サーバーの詳細はこちら](/servers/cho/)

:::

## ライフサーバー

**「自由」とラグの少なさをテーマにした、ベータ公開サーバーです。**

他のサーバーとは逆に「禁止されているMOD以外は自由に導入できる」というスタンスを採用しており、好きなMODを使って自分なりの遊び方ができます。サーバーソフトウェアにFoliaを採用し、大人数でも快適に遊べるよう設計されています。

- MOD導入の自由度が高い（禁止MOD以外は基本的に自由）
- Foliaによる軽量な動作、LagFixerによるラグ対策
- PlayerGuard（土地保護）とBolt（チェスト等の保護）を併用
- プレイ日数に応じて、保護できるブロック数が増加

:::tip[詳しく知りたい場合]

[ライフサーバーの詳細はこちら](/servers/life/)

:::

## NEarthサーバー

**1:326スケールの地球再現マップで、建国・経済・戦争が楽しめるMMOサーバーです。**

日本国内でも最大級のスケールとなる地球再現マップの上で、Landsプラグインを使った町・国づくりや、金本位制の経済システム、戦争などのリアルな生活要素を楽しめます。

- 1:326スケールの巨大な地球再現マップ
- Landsによる土地管理・戦争機能（統合版にも対応）
- G（ゴールド）と金インゴットによる金本位制の経済システム
- mcMMOやJobs、QuickShopなど、生活を豊かにするプラグインを多数導入

:::tip[詳しく知りたい場合]

[NEarthサーバーの詳細はこちら](/servers/nearth/)

:::
