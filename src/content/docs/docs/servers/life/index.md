# ライフサーバー

**ライフサーバー** は、「自由」を一番に、従来のサーバーで課題となっていた重さ（ラグ）の解決を目指して設計された、Nekozouneko Serverのベータ公開サーバーです。遊び方は人それぞれであることを大切にしており、他のサーバーとは異なるルールや制度が採用されています。

## サーバーの基本情報

| 項目 | 内容 |
| --- | --- |
| サーバー名 | ライフ |
| 対応バージョン | 1.21.8（推奨。他のバージョンでも参加可能ですが、要素や動作は1.21.8基準です） |
| サーバーソフトウェア | Folia（軽さを重視した設計） |
| 定期再起動 | 毎日午前6:00 |
| ワールドボーダー | 半径30,000ブロック（今後、徐々に拡大予定） |

## 主な特徴

- **MODの自由度が高い**：他のサーバーでは「許可されたMODのみ導入可能」というルールが一般的ですが、ライフサーバーでは「禁止MOD以外は導入してもよい」という逆のスタンスを採用しています。バグ利用MODやハッククライアントなど、一部のMODは禁止されています。
- **Foliaによる軽量な動作**：サーバーソフトウェアにFoliaを採用しており、大人数でプレイしてもラグが起きにくいよう設計されています。
- **LagFixer**：エンティティや落ちているアイテム、大規模な回路によるラグを防ぐプラグインです。5分に1度、モンスターや落ちているアイテムが削除されますが、名札を付けたモブは消えません。

## 導入されている主なプラグイン

| プラグイン | 内容 |
| --- | --- |
| mcMMO | 各行動にレベルやスキル、アビリティを追加するプラグインです。国家サーバーや超サーバーにも導入されています。 |
| AxGraves | 死亡時にお墓を生成するプラグインです。KeepInventoryの代替として、5分間はアイテムを保存してくれます。 |
| PlayerGuard | 土地を保護し、他のプレイヤーができること・できないことを調整できるプラグインです。サバイバル系サーバー全てに導入されています。 |
| HuskHomes | `/rtp` や `/sethome` などが使えるプラグインです。自分の拠点を公開ホームとして設定し、他のプレイヤーに訪れてもらうこともできます。 |

## 保護に関する注意事項

- 土地保護には **PlayerGuard**、チェストやかまどなど個別のブロック保護には **Bolt**（従来のLWCに近いプラグイン）を利用できます。
- PlayerGuardでは、他者の土地から80ブロック以内に近い場所があると、新たに保護できない場合があります。`/flags` から、自身の保護周辺で他者が保護することを許可する設定もできますが、これはトラブルをなるべく避けるための仕組みのため、利用は自己責任となります。

## 保護できるブロック数について

PlayerGuardで保護できるブロック数は、サーバーでの累計プレイ日数に応じて増えていきます。最初は60,000ブロックを保護でき、その後はプレイ日数に応じて徐々に増加し、60日以降で上限に達します。

| プレイ日数 | 保護ブロック数 |
| --- | --- |
| 1日（24時間） | 60,000ブロック |
| 3日（72時間） | 86,534ブロック |
| 5日（120時間） | 102,598ブロック |
| 10日（240時間） | 129,266ブロック |
| 20日（480時間） | 162,865ブロック |
| 30日（720時間） | 186,433ブロック |
| 40日（960時間） | 205,197ブロック |
| 50日（1200時間） | 221,041ブロック |
| 60日以降（1440時間以降） | 234,892ブロック（最大） |

## 主なコマンド（HuskHomes）

| コマンド | 内容 |
| --- | --- |
| `/back` | 死亡した場所に戻ります（死亡直後のみ使用可能）。 |
| `/sethome [ホーム名]` | ホームを作成します（最大20個まで）。 |
| `/delhome [ホーム名]` | ホームを削除します。 |
| `/home [ホーム名]` | 指定したホームへテレポートします。 |
| `/edithome [ホーム名] rename [名前]` | ホームの名前を変更します。 |
| `/edithome [ホーム名] description [説明]` | ホームに説明を設定します。 |
| `/edithome [ホーム名] relocate` | ホームの場所を、今いる場所に再設定します。 |
| `/edithome [ホーム名] privacy` | ホームの公開・非公開を切り替えます（初期状態は非公開）。 |
| `/homelist` | 自分のホームを一覧表示します。 |
| `/publichomelist` `(/phomes)` | 公開されているホームを一覧表示します。 |
| `/publichome` `(/phome) <ホーム名>` | 公開されているホームへテレポートします。 |
| `/rtp` | ランダムな場所へテレポートします。 |
| `/tpa <プレイヤー名>` | 指定したプレイヤーへのテレポートをリクエストします。 |
| `/tpaccept` | テレポートリクエストを許可します。 |
| `/tpdeny` | テレポートリクエストを拒否します。 |

:::tip[保護プラグインの使い方を知りたい場合]

PlayerGuardの詳しい使い方は、[PlayerGuardとは](/playerguard/) を確認してください。

:::
