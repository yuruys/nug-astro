# 超サーバー

**超サーバー** は、Nekozouneko Serverで遊べるサーバーの1つです。「サバイバルじゃ、物足りない、この“便利さ”をモットーに。」を掲げ、通常のサバイバル要素に加えて、mcMMOやペット、便利なコマンドなど、より快適に遊べる要素が詰め込まれています。

## 超サーバーとは

超サーバーは、マインクラフトに慣れていて、本来のサバイバル要素だけでは物足りないというプレイヤーに向けたサーバーです。月替わりのワールド更新や、通常のサバイバルにはない自然生成物、mcMMOによるスキル・アビリティなど、普段とは違ったサバイバル体験を楽しめます。

## 主な特徴

- **月1のワールド更新**：毎月1日にメインワールドが新しいワールドに切り替わります。前の期にはなかった、さまざまな建造物との出会いを楽しめます。エンダーチェスト・mcMMO・ペットの情報は更新されず引き継がれるため、大事なアイテムはエンダーチェストに入れておくのがおすすめです。
- **追加の自然生成物**：通常のサバイバルにはない建造物や要塞が自然生成されます。地面や地下だけでなく、空にも隠れている場合があるため、探索のしがいがあります。
- **初期スポーンの区分け**：初期スポーンの周囲には、25×25の区画が合計144個用意されています。他のプレイヤーと交流しやすい初期スポーン周辺に、自分の建築を立てることができますが、早い者勝ちのため区画を確保したら早めに土地保護や看板を設置しておくのがおすすめです。
- **スキル・アビリティ（mcMMO）**：mcMMOプラグインにより、ツールの使用や行動に応じてレベルが上がり、さまざまなスキル・アビリティが使えるようになります。`/mcstats` で自分のスキル情報を確認できます。

## 遊び方の流れ

1. **サーバーに参加する**：参加すると初期スポーンに配置されます。初期スポーンから4方向に区画が広がっており、しばらく進むと通常のワールドが続いています。まずは近くで土地を探したり、一緒に遊ぶ仲間を探してみましょう。
2. **サバイバルを安定させる**：木を切ったり、家を建てたり、装備を整えたりして、基本的なサバイバル生活を安定させましょう。特に食料は不足しがちなので、早めに集めておくのがおすすめです。
3. **mcMMOに触れる**：サバイバルを進めていると、画面上部にスキル情報が表示されるようになります。これがmcMMOです。スキルレベルやパワーレベルを育てて、スキル・アビリティを積極的に使ってみましょう。
4. **ペットを捕まえる**：探検中に出会った動物やモンスターを、リードを使って倒すことで、ペットとして飼いならすことができます。

## 主なコマンド

| コマンド | 内容 |
| --- | --- |
| `/hub` `[/lobby]` | ロビーサーバーに戻ります。 |
| `/deathlog` `[/dl]` | キルログの受け取り方を設定します。 |
| `/sm` | 「棒メニュー」と呼ばれる総合メニューを開きます。 |
| `/spawn` | サーバーの初期スポーン地点に戻ります。 |
| `/mcstats` | 自分のmcMMO情報を確認します。 |
| `/petc` | ペットを今いる場所に呼び出します。 |
| `/petname <名前>` | ペットの名前を変更します。 |
| `/petrelease` | ペットを野生に返します。 |
| `/pcst` | ペットのスキルを変更する画面を開きます。 |
| `/sethome <ホーム名>` | 今いる場所をホームとして保存します。 |
| `/home <ホーム名>` | 保存したホームへテレポートします。 |
| `/deletehome <ホーム名>` | 保存したホームを削除します。 |
| `/co inspect` `[/co i]` | クリックした箇所のブロック破壊・設置や、チェストへの出し入れなどのログを表示するモードに切り替えます。 |
| `/cinfo` | クリックしたチェストの保護情報を表示します。 |
| `/lock` | クリックしたチェストをロックします（設置時には自動でロックがかかります）。 |
| `/unlock` | クリックしたチェストのロックを解除します（自分がロックしたチェストのみ）。 |
| `/chopper on` | 保護状態を維持したまま、ホッパーからそのチェストへのアイテム移動を許可します。 |
| `/cmodify <プレイヤー名>` | 指定したプレイヤーのみ、クリックしたチェストのロックを解除できるようにします。 |
| `/sit` | その場に座ります。 |
| `/lay` | その場に寝っ転がります。 |

:::tip[マップ・保護システムについて]

- ワールドの様子は [Webマップ](https://cho.nekozouneko.net/) から確認できます。
- 建築物の保護には、独自開発の保護プラグインが使われています。詳しくは [保護プラグインの詳細](/playerguard/) を確認してください。

:::
