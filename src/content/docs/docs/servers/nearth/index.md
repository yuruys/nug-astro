# NEarthサーバー

**NEarthサーバー** は、日本国内でも最大級のスケールとなる1:326で地球を再現したアースマップ上で、建国・経済・戦争といったリアルな生活要素を楽しめるMMOサーバーです。

## サーバーの特徴

- **日本史上初の1:326スケールの巨大地球再現マップ**：多くの地球再現サーバーが1:500スケールに留まる中、Nekozouneko Serverならではの大人数・大規模なプレイを実現しています。
- **軽量設計でラグの心配なし**：大規模なマップを一定間隔で区切り、各地で処理を分散させる技術により、1つのワールドに大人数がいても快適にプレイできます。
- **Landsによる本格的な国家運営**：土地の管理だけでなく戦争機能も標準搭載しており、統合版でも利用できます。

## サーバーの基本情報

| 項目 | 内容 |
| --- | --- |
| バージョン | 1.21.8 |
| ソフトウェア | Folia |
| マップ縮尺 | 1:326（x: -61440, z: -30720 〜 x: 61440, z: 25600） |
| 定期再起動 | 毎日午前6:05 |

アースマップは、地球の地理データや気候区分をそのまま再現しています。南部・北部では寒冷なバイオーム、赤道付近では温暖なバイオームが生成されるなど、地域によって気候や鉱石の分布に違いがあります。

## 経済システム

NEarthサーバーの通貨単位は「G（ゴールド）」で、1G＝金インゴット1個とする金本位制を採用しています。金インゴットは `/spawn` にある換金所（チェストショップ）で仮想通貨と交換できます。

金本位制を維持するため、以下のような制限が設けられています。

- ゾンビピグリンから金がドロップしません。
- 金の装備・ツールを精錬できません。
- ネザー金鉱石からの金塊のドロップ率が大幅に低く設定されています。
- ネザーでは金ブロックを破壊してもドロップしません（ピグリン要塞での大量入手を防ぐため）。

## 導入されている主なプラグイン

| プラグイン | 内容 |
| --- | --- |
| Lands | 町や国を建てられるプラグインです。土地の管理機能や戦争機能が標準で搭載されています。 |
| mcMMO（Forked） | MMORPGのようなレベリングシステムや、スキル・パーティー機能を追加します。 |
| QuickShop | 自分だけのショップを建てて、アイテムを売買できます。 |
| Jobs | 職業に応じて仕事をすると職業ポイントがもらえ、生活や建国・戦争に役立つアイテムと交換できます。 |
| Bolt（Forked） | チェストや樽、かまどなどのブロックを保護できます。 |
| squaremap | Web上でワールド全体を見られるようにするプラグインです。 |
| LagFixer | 細かなパフォーマンス調整を行うプラグインです。 |
| HuskHomes | ホームコマンドやテレポートリクエスト（TPA）などの便利なコマンドを追加します。 |
| BetterRTP（Forked） | ランダムテレポート（`/rtp`）機能を追加します。 |
| TheosisEconomy（Forked） | `/bal`、`/baltop` などの経済機能を実装します。 |

「Forked」と表記されているプラグインは、Nekozouneko Groupによって機能追加やバグ修正が行われた独自版です。

## よく使うコマンド

| コマンド | 説明 |
| --- | --- |
| `/menu` | NEarthサーバーの総合メニューを開きます。 |
| `/spawn` | 広場（換金所あり）へ移動します。 |
| `/hide` | Webマップから自分の姿を消します。 |
| `/unhide` | Webマップに自分の姿を表示させます。 |
| `/coordinate <緯度> <経度>` | 現実の緯度・経度を、アースマップ上の座標に変換します。 |
| `/rule` | サーバーのルール（附則）を確認します。 |
| `/co i` | インスペクターモード（操作ログ確認モード）を切り替えます。 |
| `/money`、`/bal`、`/balance` | 自分の残高を確認します。 |
| `/baltop`、`/balancetop` | サーバー内の残高ランキングを表示します。 |
| `/pay <プレイヤー名> <金額>` | 指定したプレイヤーにお金を支払います。 |
| `/paytoggle` | 他のプレイヤーからの支払いを受け付けるかどうかを切り替えます。 |
| `/jobs browse` | 就職できる仕事の一覧を開きます。 |
| `/jobs points` | 現在のJobsポイントを確認します。 |
| `/jobs shop` | Jobsのショップを開きます。 |
| `/randomtp`、`/brtp` | マップ上のランダムな場所へテレポートします。 |
| `/sethome <ホーム名>` | ホームを設定します（5個まで）。 |
| `/home <ホーム名>` | 設定したホームへテレポートします。 |
| `/delhome <ホーム名>` | 設定したホームを削除します。 |

LandsとHuskHomesの詳しいコマンドは、それぞれのページを確認してください。

## サーバールールの主なポイント

以下は、正式なルール（附則）の要約です。詳しくは、公式サイトのルールページを確認してください。

- 町や国、役職の名前を不適切なものにしたり、それらを使ったなりすましをしたりしないでください。
- アカウントは、メイン・サブ合わせて3個までしか参加できません。
- アースマップを極度に改変しないでください。
- 戦争機能以外で、嫌がらせや攻撃行為を行わないでください。
- 町や国のオーナーは、その集団の責任者として、所属者がルールに違反していないか監視する必要があります。
- 運営がルール違反と判断した場合、まず警告が行われますが、改善が見られない場合は、町や国の強制解散や土地の再生成が行われることがあります。

- Jobsの詳しい使い方は、[Jobsとは](/jobs/) を確認してください。
